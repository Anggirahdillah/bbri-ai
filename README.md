# BBRI-AI

BBRI-AI is a stock analysis and forecasting application for Bank Rakyat Indonesia (BBRI) stock.

The project uses historical market data, data visualization, and machine learning to analyze stock movements and generate future price forecasts.

## Features

- BBRI stock market analysis
- Historical stock data visualization
- 7, 14, and 30-day forecasting
- Machine learning with LightGBM
- Model evaluation using RMSE, MAE, and MAPE
- Interactive dashboard using Streamlit

## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- LightGBM
- Scikit-learn
- Plotly
- Matplotlib
- Yahoo Finance
